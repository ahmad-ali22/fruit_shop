# Fruit Shop UI 🍎

A vibrant and modern E-commerce UI kit built with **Flutter**. This project focuses on high-fidelity design implementation, translating a Figma mockup into a smooth, responsive mobile experience.

---

## 🎨 Design Showcase
This project demonstrates pixel-perfect UI implementation, focusing on clean aesthetics and intuitive user flow.

## ✨ UI Features

### 🚀 Smooth Onboarding
- **Interactive Splash Screen**: Features a professional slide-action transition to welcome the user into the app.

### 🏠 Intuitive Dashboard
- **Personalized Header**: Custom user profile section with a search bar for quick navigation.
- **Horizontal Category Filtering**: A smooth, horizontally scrollable bar to filter fruits by category.
- **Product Grid**: A clean **GridView** implementation displaying all available products in a structured, easy-to-read format.

### 📄 Detailed Product View
- **Rich Content Display**: A dedicated screen showcasing product imagery, detailed descriptions, and pricing layouts, matching the Figma design specifications.

---

## 🛠️ Technical Highlights
- **Figma-to-Flutter**: Focuses on exact spacing, typography (Google Fonts), and color palettes provided in the design.
- **Responsive Layouts**: Uses `MediaQuery` and flexible widgets to ensure the UI looks great on different screen sizes.
- **Custom Widgets**: Extensive use of reusable components to keep the code DRY (Don't Repeat Yourself).

## 🚀 How to Run
1. Clone the repo: `git clone https://github.com/ahmad-ali22/fruit_shop.git`
2. Install dependencies: `flutter pub get`
3. Run the app: `flutter run`
